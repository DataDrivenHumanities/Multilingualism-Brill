# GitHub Pages CFP Site

This folder contains a ready-to-upload GitHub Pages site for the call for chapter contributions.

## Files

- `index.html` — the webpage
- `styles.css` — styling for the page

## How to publish on GitHub Pages

1. Create a new GitHub repository, or open an existing one.
2. Upload `index.html` and `styles.css` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/root` folder.
6. Save. GitHub will generate the public URL.

## Editing

To change deadlines, titles, editors, or bibliography entries, edit `index.html` directly. To change colors or layout, edit `styles.css`.
